# Gold Alert Pro v59.2

## Live Price Engine Fix

- Replaced the fragile TGJU parser with an adaptive parser that checks structured fields, stable `geram18` identifiers, Persian labels, and both Persian/Arabic-Indic digits.
- Added optional `TGJU_JSON_URL` for a structured TGJU-compatible endpoint.
- Removed the burst behavior that tried five TGJU pages on every failed poll. One primary request is made per cycle, followed by at most one fallback.
- Added TGJU parse/backoff protection to reduce repeated upstream requests after markup/parser failures.
- TGJU remains the fast display source; Servix is used as a structured validation peer and is protected by a long poll interval/circuit cooldown after HTTP 429.
- Tindex remains tertiary and is only contacted when the primary sources do not produce a usable quote.
- LIVE/STALE state now considers both source timestamp and actual receive timestamp.
- SSE remains enabled; a new valid price or source timestamp is pushed immediately to connected browsers.
- Default engine poll interval: 8 seconds.

## Important

No upstream source can guarantee zero delay. TGJU itself publishes market data on its own cadence, and public scraping should remain rate-limited. The application therefore reports LIVE only when it has a fresh received quote and reports STALE/OFFLINE otherwise.
- Fixed a second status bug: cached provider data can no longer be converted into a fake LIVE state.
- Fixed the tick error path so prolonged provider failure changes the engine to STALE/OFFLINE instead of leaving an old LIVE badge on screen.
