# Gold Alert Pro v59.1

- Live engine status is now truthful: LIVE / STALE / OFFLINE.
- TGJU live path now prefers `gem.tgju.org/profile/geram18` and parses the latest intraday tick timestamp.
- Servix is protected by a long polling interval and circuit breaker; HTTP 429 is not retried in a fast loop.
- Servix `businessTime`, freshness and peer validation are tracked.
- TGJU requests are rate-limited and fallback URLs are used only when necessary.
- Source diagnostics now expose cooldown/backoff status.
- SSE remains the browser delivery path; only valid fresh market ticks create candles.
- Stale cached prices no longer masquerade as fresh ticks or append fake candle points.
- UI source badge now shows LIVE, STALE or OFFLINE instead of always claiming the engine is live.

## Environment

Recommended defaults:

- `POLL_MS=5000`
- `SERVIX_POLL_MS=1800000` (30 minutes; protects the daily quota)
- `SERVIX_429_COOLDOWN_MS=21600000` (6 hours)
- `TGJU_MIN_REQUEST_MS=5000`

Servix credentials remain server-side only.
