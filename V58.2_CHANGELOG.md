# Gold Alert Pro v58.2.0

## Live Price Engine
- Primary 18K source changed to authenticated Servix `GOLD_18_RLS`.
- TGJU HTML remains the primary fallback when Servix is unavailable.
- Tindex remains a secondary fallback when configured.
- Servix `businessTime` is preserved as the source timestamp.
- Backend polling defaults to 5 seconds and is configurable with `POLL_MS` (minimum 3 seconds).
- Added `/api/stream` Server-Sent Events (SSE) endpoint.
- Browser market updates are pushed through SSE instead of polling `/api/state` every 10 seconds.
- Browser automatically falls back to `/api/state` polling if SSE is unavailable.
- SSE sends an update only when the market snapshot actually changes.
- Added SSE heartbeat and no-cache headers for proxy compatibility.
- Version bumped to 58.2.0.
