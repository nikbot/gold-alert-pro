# V60.0.0 — Gold Alert Pro FULL ADMIN CONTROL CENTER

## Admin Control Center
- Added a dedicated `/admin` SaaS-style management dashboard.
- Responsive sidebar, header, cards, dynamic charts, toast notifications, loading/empty/error states.
- Dark/Light theme toggle.
- Mobile-friendly layout.

## Super Admin & Security
- Secure HttpOnly admin session cookie with SameSite=Lax.
- Server-side session persistence with expiration.
- Rate-limited admin login attempts.
- Origin validation for admin mutations.
- Login logs with IP and device information.
- Active admin session management and revoke controls.
- SUPER_ADMIN / ADMIN / MODERATOR / PREMIUM_USER / USER role model.
